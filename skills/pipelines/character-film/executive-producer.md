# Character Film — Executive Producer

This beta manifest implements the path from story through final movie review.
Validate it through Experiments A–E in order with real approved inputs; a
synthetic render does not establish character consistency. Phase 7 improvements
wait until a real small film succeeds. Follow `AGENT_GUIDE.md` for preflight, tool discovery,
review, checkpointing, and user-facing decisions.

Start with the story. Present a concrete story bible, accept revisions, and
record explicit user approval before setting `LOCKED`. Character discovery may
then identify the cast and privacy requirements. Character lock is a hard gate:
the stage remains incomplete until approved reference images and outfits exist.

Keep all project files under `projects/<project-id>/`. Source photos are never
uploaded merely because a provider or selector is available. A local-only
source photo may not be passed to any remote host, including an agent-native
image tool. Record a separate explicit permission if the user later allows
remote character creation. Do not substitute providers after a privacy or
policy blocker without the user's approval.

The reviewer skill is advisory for creative quality. Story and character lock
rules are deterministic gates and cannot be waived by PASS_WITH_WARNINGS.
