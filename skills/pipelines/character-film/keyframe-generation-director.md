# Keyframe Generation Director

Read the shot plan and locked character bible. For each shot, generate one
frame using only the derived identity, outfit, and approved scene references.
Treat host image generation as agent-native. Read its Layer 3 instructions and
announce provider, model, and sample or batch choice before a call. Register
the resulting file and provenance in the project. Never route a source photo
to `image_selector` or silently choose an alternative provider.

The Continuity Supervisor compares the frame with the locked master, full
body, outfit, age category, and prior shot state. The Creative Director checks
composition, action, location, and story beat separately. Record both reviews
in `film_keyframes`. A continuity failure blocks video generation even when
the frame is attractive. Revise the prompt or escalate to human review within
the approved retry and budget limits. Only checkpoint completed when every
shot has both `pass` verdicts and the files still match their hashes.
